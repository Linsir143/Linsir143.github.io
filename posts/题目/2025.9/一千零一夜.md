# 一千零一夜

对非负实数$x,y,z$，以下一千零一次不等式成立 
$$
\sum_{\mathrm{cyc}}{\left( x^{1001}-x^{999}\!\:y\!\:z \right)}\ge 1683x^{333}y^{333}z^{333}\sum_{\mathrm{cyc}}{\left( x^2-yz \right)}
$$

###  证明

$x,y,z$  有取 $0$ 的显然成立. 若 $x,y,z$ 有两者相等，设 $y=z=1$，剩下的一元多项式不等式可以高效地验证成立.

```
f = PolynomialQuotient[
   x^1001 + y^1001 - x^999 y z - x y^999 z - x y z^999 + z^1001 - 
     1683 x^333 y^333 z^333 (x^2 - x y + y^2 - x z - y z + 
        z^2) /. {y -> 1, z -> 1}, (x - 1)^2, x
   ];
Reduce[f < 0 && x >= 0] // AbsoluteTiming
```

使用带余除法获得显式证明

```
{q, r} = PolynomialQuotientRemainder[f  , (x - 123358/123623)^2, x];
CoefficientList[{q, r}, x] // Min // # >= 0 &
```

从而只需考虑 $x,y,z$ 两两不等的情况，设 $x+y+z=1$，定义域自然有界，边界上不等式显然成立，只需考虑内部极值，由拉格朗日乘数法获得等式，差分消去乘数并约去 $x-y$等因子

```
grad = D[
   x^1001 + y^1001 - x^999 y z - x y^999 z - x y z^999 + z^1001 - 
    1683 x^333 y^333 z^333 (x^2 - x y + y^2 - x z - y z + z^2) + 
    k (x + y + z - 1), {{x, y, z}}];
l1 = {PolynomialQuotient[grad[[1]] - grad[[2]], x - y, x],
    PolynomialQuotient[grad[[2]] - grad[[3]], y - z, y],
    PolynomialQuotient[grad[[3]] - grad[[1]], z - x, z]} // Expand;
```

现在考虑

```
g = Expand /@ PolynomialQuotient[Collect[l1[[1]] - l1[[2]], x], x - z, x] ;
```

则可以验证 $g$ 是对称的且 $g=0$，再证明 $g$ 是严格正的从而矛盾，

```
cfr = Association@SortBy[CoefficientRules[g], Sort@*Keys];
```

只有 $x^{334}y^{332}z^{332}$ 及其轮换系数是负的，只有 $\left( 333,333,332 \right) \prec \left( 334,332,332 \right) $，由米尔黑德不等式，只需验证 

`cfr[[1 ;; -4]] // Total` 非负，

```
cfr[[1 ;; -4]] // Total
(* 2805183 *)
```
实际上不需要 $\sum x^{998}$ 参与即可把负项消掉，故 $g$ 严格正，说明没有 $x,y,z$ 互不相等的内部极值点，有相等的已经验过成立.
